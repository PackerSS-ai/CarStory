# Личный медиархив

В папке уже находится полный подготовленный публичный медианабор:

- `reference-sheet.webp` — утверждённый многовидовой референс Scion FR-S, очищенный от номерных знаков и обозначения GT86;
- `hero-reference.webp` — кинематографичный визуал первого экрана по утверждённому референсу, без номерных знаков;
- `auction-01.webp` … `auction-04.webp` — аукционные кадры;
- `build-01.webp`, `build-02.webp` — реальные кадры установки Rocket Bunny;
- `current-01.webp`, `current-02.webp` — два актуальных ракурса без читаемых номерных знаков;
- `neurocore-community-logo.png` — официальный логотип в исходных цветах и пропорциях;
- `autofest-2026.webp` — реальная фотография автомобиля на AutoFest 2026 из архива владельца;
- `poster-widebody-edition.webp`, `poster-gallery-suspended.webp`, `poster-wet-run.webp`, `poster-bottle.webp` — четыре художественных постера, отделённые на сайте от документального архива.
- `ai-cartoon-01.webp`, `ai-cartoon-02.webp`, `ai-cartoon-03.webp` — три предоставленных владельцем примера кадров из ИИ-мультфильмов; изображения только пропорционально уменьшены и переведены в WebP без ретуши и кропа.

Не добавляйте в публичную папку исходный необработанный reference sheet: он содержит данные, которые не должны попадать на сайт. Для публикации используйте только очищенный `reference-sheet.webp`.

На реальной фотографии AutoFest сохранён исходный номерной знак. На очищенном reference sheet номерных знаков нет.

Официальный логотип NEUROCORE community обрезан только по пустым чёрным полям, чтобы занимать всю ширину блока; цвета и пропорции wordmark не изменены.
