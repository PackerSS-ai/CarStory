# Scion FR-S 2015 — One Car / One Story

Премиальный одностраничный сайт-история личного Scion FR-S 2015. Проект построен как эмоциональная воронка: история машины привлекает внимание, показывает реальный путь Никиты в сфере нейросетей и мягко переводит заинтересованного посетителя в Instagram.

Сайт собран на React/Vinext, адаптирован для компьютеров и телефонов и подготовлен к публикации через OpenAI Sites / Cloudflare.

## Концепция воронки

1. **Мечта.** Первый экран знакомит с автомобилем и задаёт кинематографичную атмосферу.
2. **История.** Хронология ведёт от аукциона в Лос-Анджелесе и сборки Rocket Bunny к первой встрече в 2020 году и исчезновению машины.
3. **Поворот через ИИ.** В 2025 году Никита меняет сферу деятельности, присоединяется к Neurocore и неожиданно снова находит именно эту Scion FR-S.
4. **Доказательство пути.** Главный акцент — машина была куплена на деньги, заработанные созданием ИИ-мультфильмов для клиентов из США. Три предоставленных кадра показывают направление работы: персонажи, мир и эмоция.
5. **Действие.** Финальный блок объединяет интерес к автомобилю и нейросетям и ведёт на страницу [@s_packer_s в Instagram](https://www.instagram.com/s_packer_s?igsh=M2FuemtoYno5OWIz&utm_source=qr).

3D-модель и отдельная 3D-секция намеренно удалены. В центре проекта остаются настоящая история, фотографии автомобиля и понятный переход к автору.

## Что реализовано

- первый экран с данными Scion FR-S 2015;
- приветствие владельца: «Привет! Я Никита и это история моего Scion FR-S»;
- полная хронология 2019–2026;
- усиленная глава о смене профессии и заработке на ИИ-мультфильмах;
- официальный логотип NEUROCORE community без изменения пропорций и цветов;
- галерея «тогда / сборка / сейчас»;
- отдельный блок с тремя примерами ИИ-мультфильмов;
- спек-лист автомобиля и настоящий кадр AutoFest 2026;
- финальный Instagram CTA с красивой кнопкой;
- адаптивная сетка, lazy loading и поддержка reduced motion;
- визуальная система мокрого асфальта, дорожной разметки, трещин, отражений, зерна и световых эффектов;
- тестовый статус сайта и запрет индексации до финального утверждения.

## Быстрый запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Адрес локального сайта появится в консоли, обычно это `http://localhost:3000`.

Проверка production-сборки:

```bash
npm test
npm run start
```

Команда `npm test` собирает проект и проверяет серверный HTML: историю, AI-воронку, три кадра мультфильмов, Instagram CTA и отсутствие 3D-компонентов или ссылок на GLB/GLTF.

Основные материалы находятся в `public/media/`.

| `build-01.webp`, `build-02.webp` | установка Rocket Bunny |
| `current-01.webp`, `current-02.webp` | актуальные ракурсы автомобиля |
| `autofest-2026.webp` | настоящая фотография с AutoFest 2026 |
| `ai-cartoon-01.webp` | пример ИИ-мультфильма: персонажи и история |
| `ai-cartoon-02.webp` | пример ИИ-мультфильма: мир и атмосфера |
| `ai-cartoon-03.webp` | пример ИИ-мультфильма: герой и эмоция |

## Важные правила

- На сайте автомобиль везде называется **Scion FR-S**. GT86 используется только как внутренняя референсная база и не должен появляться в опубликованном тексте.
- AutoFest 2026 показывается только настоящей фотографией из архива владельца.
- Три кадра ИИ-мультфильмов — примеры направления работы Никиты, а не кадры из истории автомобиля.
- Instagram-ссылка должна вести на `@s_packer_s` и открываться в новой вкладке.
- Пока сайт помечен как тестовая версия, индексация поисковиками отключена.
